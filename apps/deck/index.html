NEXUS DECK V1.1

Seu painel está pronto.

01

Use o Nexus Local

Para controle real do Windows, abra no Safari do iPad o endereço mostrado pelo Nexus Companion. O Vercel continua útil para preview e distribuição.

02

Pareie com segurança

No painel do Windows, gere um código de 6 dígitos. Depois toque em “Nenhum PC” no topo do iPad e informe o código. O dispositivo fica autorizado localmente.

03

Personalize o seu Deck

Use “Editar deck” para criar botões, sliders, macros, páginas e perfis inteligentes. As alterações ficam salvas neste iPad.

✓

Pronto para trabalhar

O Companion pode iniciar com o Windows e ficar na bandeja. Se algo falhar, use o diagnóstico rápido aqui ou o diagnóstico completo no painel do Windows.
